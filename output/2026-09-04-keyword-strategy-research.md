# 키워드 전략 - 9월 4주 콘텐츠 계획

> 조사일: 2026-09-04
> 도구: Claude Code (data/search_performance.csv 분석)
> 출처: 내부 검색 성과 데이터 (data/search_performance.csv), 우선순위 평가는 이전 대화에서 진행한 3기준(구매의도·강점적합도·순위상승용이도) 채점 결과 기반
> 성격: 내부 참고용 콘텐츠 기획안입니다. 발행 전 각 주차 실제 콘텐츠는 brand-voice 톤 적용 및 seo-checklist 검수를 거쳐야 합니다.

## 선정 기준 요약

평균순위 11~20위, 노출수 100회 이상 키워드 10개 중 아래 3가지 기준으로 채점(상3·중2·하1)한 총점 상위 4개를 선정했습니다.
1. 구매의도: 콘텐츠를 보고 실제 행동(도구 도입·서비스 검토 등)으로 이어질 가능성
2. 강점적합도: 픽온이 실제 보유한 스킬·운영 경험과 얼마나 맞닿아 있는가
3. 순위상승용이도: 현재 평균순위·클릭 추이로 볼 때 상위 노출까지 끌어올리기 쉬운가
