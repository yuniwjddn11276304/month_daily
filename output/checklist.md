# 콘텐츠 발행 전 체크리스트 (my-checklist)

이 문서는 `.claude/skills`·`.claude/agents` 평가에 썼던 기준(라우팅·모델 정합성 / 안전장치 실효성 / 저장 규칙 / 역할 경계 / 형식 완성도 / 산출물 정합성)을,
**개별 콘텐츠(blog · sns · newsletter · ad · research)를 발행하기 전에 검사하는 체크리스트**로 바꾼 것이다.
`seo-checklist` 스킬(형식 위주)이 놓치는 "사실검증·안전장치" 항목을 메꾸는 용도로 함께 쓴다.

---

## 0. 즉시 반려 조건 (하나라도 해당하면 점수와 무관하게 반려)

- [ ] 검증되지 않은 숫자·통계를 출처 없이 인용했다
- [ ] 경쟁 서비스를 깎아내리거나 상표를 직접 언급했다
- [ ] 과장 표현을 썼다 — 최고 · 완벽 · 업계 1위 · 100% 보장
- [ ] `*-research.md` 자료의 문장·수치를 이 검수 없이 그대로 옮겨 발행하려 한다
- [ ] `data/` 폴더 CSV, `business_info.md`의 임시값을 실수치인 것처럼 인용했다
- [ ] PICKON이 실제로 팔지 않는 상품·효능(예: 스킨케어 성분)을 파는 것처럼 썼다

→ 하나라도 체크되면: 수정 후 재검수. 아래 100점 채점은 진행하지 않는다.

---

## 1. 공통 항목 (모든 종류, 20점)

100점 중 20점은 종류에 상관없이 공통으로 적용한다.

| 항목 | 감점 |
|---|---:|
| brand-voice 톤 위반 (호칭 "OO님"·어미 "~해요" 미준수, 한 문장 40자 초과) | -10 |
| 저장 경로/파일명 규칙 위반 (`output/YYYY-MM-DD-종류-주제.md`) | -10 |

---

## 2. 종류별 항목 (80점)

해당하는 종류의 표만 채점하고, 공통 20점과 합산해 100점 만점으로 판정한다. **80점 이상이면 발행 승인.**

### 📝 blog

| 항목 | 감점 |
|---|---:|
| 분량 2,000자 미만 | -15 |
| H2 대제목 3개 미만 | -10 |
| 제목 30자 초과 / 메타 설명 없음·80~120자 이탈 | -15 |
| 키워드가 제목·첫 문단·H2 중 1곳·마무리에 배치되지 않음 | -15 |
| 이미지 대체 텍스트([이미지: 설명]) 없음 | -10 |
| 내부 링크 0개 | -10 |
| 리서치 기반 글인데 참고 자료 출처 표기 누락 | -5 |

### 📱 sns

| 항목 | 감점 |
|---|---:|
| 본문 150자 초과 | -20 |
| 해시태그 10~15개 범위 이탈 | -15 |
| 후킹 → 포인트 → 행동유도 3단 구조 미준수 | -20 |
| 한 캡션에 메시지 두 개 이상 | -15 |
| 이모지 남발 (문단당 3개 이상) | -10 |

### 📧 newsletter

| 항목 | 감점 |
|---|---:|
| 제목 30자 초과 | -15 |
| 본문 500~800자 범위 이탈 | -20 |
| 링크 3개 초과 | -15 |
| 5단 구조(제목·첫줄·본문·실행제안·맺음) 중 누락 항목 있음 | -15당 항목 |
| 한 호에 주제 2개 이상 다룸 | -15 |

### 📢 ad-copy

| 항목 | 감점 |
|---|---:|
| 제목 25자 초과 | -20 |
| 설명 45자 초과 | -20 |
| PAS(문제-동요-해결) 구조 미준수 | -20 |
| 매체 심사 거부 소지 표현(최고·1위·100% 보장) | -20 (0. 즉시반려와 중복 체크) |
| 경쟁사 상표 직접 언급 | -20 (0. 즉시반려와 중복 체크) |

### 🔎 research (내부 참고자료 — 발행 대상 아님)

발행 승인 개념이 아니라 "리서치 자료로 활용해도 되는가"를 판정한다. 80점 미만이면 blog-writer 등에 재료로 넘기지 말고 보완부터 한다.

| 항목 | 감점 |
|---|---:|
| 문서 첫머리에 조사일·조사 도구·출처 없음 | -20 |
| 사실·숫자·인용 옆에 출처 URL이 없음 | -25 |
| 미확인 정보를 "미확인" 대신 "관측값"·"추정" 등 임의 라벨로 남김 | -15 |
| "내부 참고용, 그대로 발행 금지" 문구 누락 | -15 |
| 경쟁사 관련 서술에 중립적이지 않은 표현 사용 | -25 |
