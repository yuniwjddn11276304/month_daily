# 리드(문의) 점수화 기준 — lead_scoring

## 개요

문의 1건당 아래 4개 항목 점수를 합산해 리드 스코어(lead score)를 산출한다. 항목별 최고점을 모두 받으면 최대 100점.

## 점수 기준

| 항목 | 기준 | 점수 |
| --- | --- | --- |
| 예산대 | 300만원 이상 / 100~300만원 / 50~100만원 / 50만원 이하 | 40 / 25 / 15 / 5 |
| 문의내용 | "견적·통화·일정·상담" 포함 / 업종·상황이 구체적이거나 가능 여부를 묻는 질문 / 단순 질문 | 30 / 15 / 0 |
| 회사(상호) | 적었다 / 안 적었다 | 15 / 0 |
| 관심상품 | 1:1 코칭·기업 교육 / 온라인 강의 | 15 / 5 |

## 산식

```
lead_score = 예산대 점수 + 문의내용 점수 + 회사 점수 + 관심상품 점수
```

최대 100점(40+30+15+15), 최소 5점(5+0+0+5).

## 참고

- 예산이 클수록, 문의 내용이 구체적(견적·통화·일정·상담 요청)일수록, 회사/상호를 기재했을수록, 관심 상품이 고관여(1:1 코칭·기업 교육)일수록 고득점.
- 이 문서는 내부 참고용 자료이며, 그대로 발행하지 않는다. 리드 스코어링에 활용할 발행물 제작 시 seo-checklist 검수를 거친다.
