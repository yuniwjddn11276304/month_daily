말투와 표현은 brand-voice 스킬의 기준을 따른다.

## 글자 수

- 제목 25자 이내 / 설명 45자 이내

## PAS 공식

- P 문제: 지금 겪는 어려움
- A 동요: 그대로 두면 어떻게 되나
- S 해결: 우리가 주는 답

## 절대 금지

- 최고 · 1위 · 100% 보장 → 매체 심사 거부 · 법적 문제 소지
- 경쟁사 상표 직접 언급
- 검증되지 않은 숫자·통계 인용

## 저장 규칙

- 결과물은 `output/` 폴더에 저장한다.
- 파일명: `YYYY-MM-DD-ad-주제.md`
