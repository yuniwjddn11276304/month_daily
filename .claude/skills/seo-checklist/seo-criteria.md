# SEO 검사 기준 (100점 만점)

항목별 배점만큼 충족 시 만점, 미충족 시 0점으로 채점한다.

## 진짜 결함 (45점) — 글 종류와 상관없이 없으면 문제

| 항목 | 배점 | 충족 조건 |
|---|---|---|
| 내부 링크 | 15점 | 내 다른 글로 가는 링크가 1개 이상 있다 |
| 상담으로 가는 길 | 15점 | 글을 읽고 나서 취할 행동(문의·상담·구매 등)과 그 링크가 있다 |
| 제목에 키워드 | 15점 | 검색될 만한 키워드가 제목에 들어 있다 |

## 기준 차이 (55점) — 글 종류에 따라 적정선이 다름

| 항목 | 배점 | 충족 조건 |
|---|---|---|
| 메타 설명 | 15점 | 검색 결과용 두 줄 요약문이 85~100자로 있다 |
| 제목 길이 | 10점 | 제목이 25~32자다 |
| 제목 구조 | 15점 | 본문에 소제목(H2)이 나뉘어 있다 |
| 이미지 설명 | 15점 | 이미지마다 설명(대체 텍스트)이 붙어 있다 |

## 비고

- 이 기준은 `seo-checklist` 스킬의 참고 자료다. 스킬 실행 시 사용하는 실제 채점 로직은 `SKILL.md`에 정의되어 있으며, 현재는 이 파일과 별도의 9항목 감점제를 쓰고 있다.
- 이 기준을 스킬의 공식 채점 방식으로 반영하려면 `SKILL.md`를 함께 수정해야 한다.
